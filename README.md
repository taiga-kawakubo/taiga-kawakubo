## <img src="https://media.giphy.com/media/LnQjpWaON8nhr21vNW/giphy.gif" width="28" /> About Me

Laravel / PHPを中心に、認証・認可、REST API、外部API連携、バッチ処理、通知、テストまで含めたWebアプリケーション開発に取り組んでいます。

BookShelfでは、書籍・レビュー・お気に入り・読書計画などの機能に加え、Sanctumを使用したAPI認証、Policyによる認可、Schedulerによる通知処理を実装しました。

また、ChatGPTやCodexを開発に活用するだけでなく、質問分類、学習記録、振り返り支援を行うプログラミング学習用AI Agentの設計・改善にも取り組んでいます。

```yaml
name: Taiga Kawakubo
role: Laravel / PHP Web Developer

  - Web application development
  - REST API / Authentication / Authorization / Testing
  - Learning-support AI Agent development
currently_building:
  - BookShelf
  - Programming Study AI Agent
goal: "基礎を固め、実務で価値を出せるエンジニアになる"
```

- Notionに学習ログを残し、理解したこと・詰まった点・改善点を振り返りながら学習しています。
- ChatGPT / CodexなどのAIを活用し、より良いコードや設計を考えながら実装しています。
- 学習者が自分で読み、考え、確認する力を育てられるAI Agentを開発しています。
